# MiRus

> MiRus is a Marietta, Georgia life sciences company (founded 2015) that develops implants and
> procedural solutions built on MoRe, its proprietary molybdenum-rhenium superalloy, for spine,
> orthopaedic and structural heart disease — plus GALILEO, a spine-focused surgical planning,
> intra-operative alignment measurement and remote physiologic monitoring platform.

## What an agent should know first

MiRus has **no public API program**. There is no developer portal, no API reference, no OpenAPI,
AsyncAPI or GraphQL schema, no SDK in any package registry, no MCP server, no A2A agent card, and
no `/.well-known/` document on any MiRus host. Do not attempt to integrate; there is nothing
published to integrate against.

MiRus does operate one real API, but it is not published: the GALILEO / "Mirus Analytics"
clinician application at `https://rpm.mirusmed.com` calls its own backend under
`https://rpm.mirusmed.com/api/`, including a FHIR route at `/api/v1/fhir`. Every route answers
`401` with `WWW-Authenticate: Bearer` (AWS Cognito JWT). It is a customer-only surface with no
public contract or reference. Access requires a MiRus clinical relationship, not a signup.

## Products

- Europa MoRe pedicle screw system — the first FDA-cleared implant in this alloy class
- CYGNUS MoRe low-profile anterior cervical plate system
- 3DR printed lumbar interbody, standalone ALIF and cervical corpectomy systems
- Atlas MoRe foot-and-ankle plating and IO expandable wedge osteotomy systems
- Siegel transcatheter aortic valve (structural heart, in clinical study)
- GALILEO Spine Alignment Monitoring System (intra-operative measurement)
- GALILEO Surgical Planning and GALILEO RPM (remote physiologic monitoring / outcomes analytics)
